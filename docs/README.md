## 🤖 AI核心功能（6大能力）

### 1. 📊 项目质量智能评估
- **0-100分综合评分**
- **4维度分析**：完整性、创新性、技术深度、呈现质量
- **输出**：项目亮点、待改进建议、技术标签、复杂度评估

### 2. 🎲 评分一致性分析
- 实时监控评委评分偏差（过严/过宽）
- 标准差计算、Z-score标准化
- AI生成个性化改进建议

### 3. 🛡️ 内容安全审核
- 自动检测敏感内容、垃圾信息
- 多级别标记（low/medium/high）
- 自动化审核建议（approve/review/reject）

### 4. ✍️ 智能内容生成
- README自动生成
- 项目描述优化
- 赛事宣传文案、评分标准生成
- 支持中英双语、多种风格

### 5. 🔍 抄袭智能检测
- 文本相似度分析（0-100%）
- 跨项目自动对比
- 疑似抄袭详细报告

### 6. 🧠 评委智能助手
- 自动生成项目摘要
- 关键技术点提取
- 评分参考建议、智能评语生成

## 🚀 3步快速上线

### 步骤1：数据库迁移（2分钟）
```bash
npx prisma migrate dev --name add-ai-assessment
npx prisma generate
```

### 步骤2：配置环境变量（1分钟）
```bash
# 编辑 .env
AI_PROVIDER=claude
AI_API_KEY=sk-ant-your-key-here
AI_MODEL=claude-sonnet-4-20250514
```

### 步骤3：注册AI路由（1分钟）
```typescript
// api/server.ts
import aiRoutes from './routes/ai'
app.use('/api/ai', aiRoutes)
```

### 启动测试
```bash
npm run dev
# 访问 http://localhost:5173/admin/projects
```
